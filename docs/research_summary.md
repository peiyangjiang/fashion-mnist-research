# FashionMNIST：模型容量、数据规模与标签噪声的受控实验研究

## 1. 项目概述

本项目是一项本科阶段的探索性机器学习研究，通过受控实验比较线性分类器与小型非线性网络在不同训练数据量和标签质量下的表现。项目关注的不只是总体准确率，还包括类别差异、初始化敏感性，以及错误训练标签下的模型行为。

项目的重点是提出可检验的问题、记录实验条件，并在证据允许的范围内解释结果。受控比较有助于区分特定配置下的观察与关于模型的一般判断。本报告不主张方法创新或理论发现。

## 2. 研究问题

1. **模型差异：** Softmax Regression 与多层感知机（MLP）的验证准确率、逐类别召回率和混淆模式有何差异？哪些差异在选定的初始化下保持一致？
2. **训练数据量：** 固定参数更新次数时，训练样本数如何影响两个模型的表现及其差距？
3. **错误标签：** 人为替换部分训练标签后，模型在干净验证集上的表现如何变化？对被改标签训练样本的预测有何差异？

## 3. 实验设置

| 项目 | 配置 |
| --- | --- |
| 数据集 | FashionMNIST，28 × 28 灰度图像，10 个类别；官方训练集划分为 54,000 个训练池样本和 6,000 个验证样本 |
| 模型 | Softmax Regression：784 → 10；MLP：784 → 128 → ReLU → 10；线性层均含偏置 |
| 优化配置 | 交叉熵损失；SGD，学习率 0.1，batch size 32；不使用动量、权重衰减或数据增强 |
| 初始化重复 | seed 42～46；每次运行重新创建模型和优化器 |
| 固定随机性 | 数据划分、训练打乱、子集选择和标签噪声使用独立生成器，适用时各自固定为 seed 42 |
| 训练预算 | 初始模型比较与初始化实验：3 个 epoch，保留不足一批的训练样本；数据量与标签噪声实验：5,000 次更新，舍弃不足一批的训练样本 |
| 比较因素 | 模型；6,000、18,000、54,000 个样本的嵌套训练子集；18,000 样本下的 0% 与 20% 标签噪声 |
| 评价指标 | 干净验证集准确率、逐类别召回率、混淆矩阵；被改标签训练样本的错误标签拟合率和原始标签准确率 |

20% 噪声条件下，恰好 3,600 个训练标签被替换，每个标签从其原始类别以外的九类中等概率选择。所有噪声组共用同一份标签改动，验证标签保持不变。官方测试集尚未评估。

数据量实验共 30 组运行，标签噪声实验共 20 组。下文结果汇总五个初始化；差值根据未四舍五入的原始计数计算。标准差描述初始化间波动，不是置信区间；准确率均值以百分比表示，标准差与差值的单位为百分点。3 个 epoch 与固定更新次数的实验还存在批次处理和训练顺序差异，因此分别解读。

## 4. 主要实验发现

### 模型与类别差异

**实际观察：** 完善随机性控制后的单个 seed 比较中，MLP 的验证准确率为 80.35%，Softmax 为 80.13%，即在 6,000 个验证样本中多预测对 13 个。在 54,000 个训练样本、3 个 epoch 和五个初始化下，MLP 与 Softmax 的平均准确率分别为 81.20% 和 80.13%。平均配对差距为 1.06 个百分点，各初始化的差距为 0.22～1.53 个百分点。

总体优势并不意味着所有类别都更好。MLP 在 Coat 和 Shirt 上的平均召回率分别高 16.71、9.07 个百分点，在 T-shirt/top 和 Pullover 上分别低 5.93、9.05 个百分点，四个方向在五个初始化中均一致。MLP 的 T-shirt/top → Shirt 错分更多，Coat → Pullover 错分更少，这两个方向也在五次重复中一致。

**可能解释：** 两个模型的决策边界可能不同，从而改变类别之间的错误分布。非线性结构和更多参数是候选因素，但本实验没有单独识别它们的作用。汇总混淆矩阵也不能确定具体的视觉原因，或同一张图片在两个模型之间如何改变预测。

### 训练数据量

**实际观察：** 使用干净标签、每组固定 5,000 次更新时：

| 训练样本数 | Softmax 准确率均值 ± 标准差 | MLP 准确率均值 ± 标准差 | 平均差距：MLP − Softmax |
| --- | --- | --- | --- |
| 6,000 | 83.60% ± 0.05 | 83.41% ± 0.33 | −0.19 个百分点 |
| 18,000 | 82.95% ± 0.10 | 85.77% ± 0.28 | +2.82 个百分点 |
| 54,000 | 83.80% ± 0.06 | 85.59% ± 0.38 | +1.79 个百分点 |

6,000 样本组中，MLP 有两次高于 Softmax；其余两个数据量下，MLP 五次均更高。两个模型的平均准确率及其差距都没有随数据量单调增加。

**可能解释：** 固定更新预算改变了接触不同图片与重复接触同一图片之间的关系。每组累计呈现 160,000 次样本，但训练集越大，每个样本的平均呈现次数越少。优化进度、子集组成和模型结构可能共同影响结果。当前观察不能确定最佳数据量，也不能说明增加数据通常会降低表现。

### 错误训练标签

**实际观察：** 使用 18,000 个训练样本、固定 5,000 次更新时：

| 模型 | 使用干净训练标签时的平均验证准确率 | 20% 错误训练标签时的平均验证准确率 | 平均下降幅度 |
| --- | --- | --- | --- |
| Softmax Regression | 82.95% | 72.77% | 10.18 个百分点 |
| MLP | 85.77% | 84.27% | 1.50 个百分点 |

在被改标签的 3,600 个训练样本上，Softmax 与 MLP 的平均错误标签拟合率分别为 3.22%、2.34%，对应原始标签的平均准确率分别为 73.11%、84.34%。MLP 的验证准确率下降更小、错误标签拟合率更低、原始标签准确率更高，这三个方向在五个配对初始化中均一致。训练终点的结果没有支持最初“MLP 可能更容易拟合错误标签”的预期。

**可能解释：** 在当前预算下，MLP 可能更有效地利用了剩余正确标签支持的分类规律。但普通分类错误也可能偶然匹配人为指定的错误标签。本实验没有记录拟合指标的训练过程曲线，也没有测量干净标签训练的模型对同一份指定错误标签的匹配率，因此不能据此确定记忆机制。

## 5. 研究局限

本研究只覆盖 FashionMNIST、一个线性模型和一个小型 MLP，没有评估 CNN 或其他现代网络结构。五个初始化共用一份验证划分、一条嵌套子集序列及一份标签噪声，并不等于五份独立评估数据；实验也没有进行统计显著性检验。

标签噪声仅包含 0% 和 20%，采用等概率改成其他类别的规则。训练预算和优化器配置固定，没有针对每种模型分别调参。模型比较同时改变参数数量与非线性结构，不能单独判断其中某项的因果作用。当前没有确认模型已收敛，保存的结果也不包含模型检查点或逐样本预测。因此，结论限于已记录的实验配置和验证集。

## 6. 后续方向

优先考虑的扩展是改变数据划分和噪声 seed、记录训练过程中的拟合指标，并补充干净标签训练模型对指定错误标签的参考匹配率。官方测试集的最终评估应在评价方案固定后开展。

小型 CNN 基线可以用于比较利用图像空间结构后，类别错误是否发生变化。保存逐样本预测和隐藏层激活，有助于错误检查与表征分析。更多噪声比例、结构化标签错误或受控输入扰动，可以扩展鲁棒性实验；更大规模数据集则适合在完善评价流程后逐步尝试。这些方向可以连接到表征、泛化和不完善监督下的学习问题，但目前尚未开展。
